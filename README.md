# Telegram AI English Tutor

A Telegram chatbot powered by Google Gemini AI that helps users practice English through interactive conversations.

## Features

- AI-powered English language assistance
- Individual conversation history for each user
- Grammar corrections and simple explanations
- /start command
- Error handling for API requests

## Technologies

- JavaScript (Node.js)
- Google Gemini API
- Telegram Bot API
- dotenv

## Getting Started

1. Clone the repository.
2. Install dependencies using `npm install`.
3. Create a `.env` file containing:
   - `GEMINI_API_KEY=your_api_key`
   - `BOT_TOKEN=your_telegram_bot_token`
4. Start the bot using `node index.js`.
